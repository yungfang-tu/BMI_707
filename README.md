# BMI_707
Deep Learning for Biomedical Data

🧬 White Blood Cell Classification with ResNet and Attention Mechanism

This project implements a deep learning pipeline to classify white blood cells (WBCs) using the Raabin-WBC dataset. Leveraging a ResNet-based convolutional neural network enhanced with an attention mechanism, the model focuses on morphologically informative regions, improving both classification performance and interpretability.
